# GTM Engine — живой прототип

Кликабельный прототип рабочего места. Каркас в духе VS Code: выдвигающееся меню слева,
плитки-вкладки в центре, помощник справа, журнал снизу.

**Три раздела:**
- **Data** — сырые данные в таблицах: поиск, сортировка, правка, проверка полноты
- **Workflows** — конструктор процессов в нотации BPMN 2.0: блоки добавляются, настраиваются, переставляются
- **Workspaces** — роль + шаблон процесса + набор данных; отображения: воронка, доска, список, таблица

Данные демонстрационные, компании и люди вымышленные.
